# 期末分組｜正式部署

正式版使用原本的成績試算表，新增單一「期末分組」工作表：
https://docs.google.com/spreadsheets/d/1kyrO7YUFh5QfwPZ-AhPfAyrUh_ktAvbNlKZBVk54fs0/edit

名單直接讀取原本「車輛一B」「機械一B」的A、B欄；車輛37人、機械排除轉學生後49人。原有成績與名單不會被後端寫入。兩班預設皆未開放。

## 標準兩檔部署方式

1. 用老師的 Google 帳號開啟上方試算表，選「擴充功能 → Apps Script」。
2. 將預設 `Code.gs` 的內容全部換成同資料夾 `Code.gs` 的完整內容。按左側「＋ → HTML」，名稱輸入 `Index`，將 `Index.html` 的完整內容貼入，兩個檔案都儲存。
3. 左側齒輪「專案設定 → 指令碼屬性」新增 `INITIAL_ADMIN_PASSWORD`，值填先前決定的管理密碼，儲存。回編輯器選 `setup` 按「執行」，授權後會在執行記錄顯示「設定完成」，不會彈出試算表對話框。成功後會自動刪除這個暫存明碼屬性，保留鹽值與雜湊。
4. 第一次部署：按「部署 → 新增部署作業」，類型選「網頁應用程式」。執行身分選「我」，誰可以存取選「所有人」。已有正式網址時：選「部署 → 管理部署作業 → 鉛筆圖示 → 版本選新增版本 → 部署」，保留原網址。
5. 複製以 `/exec` 結尾的網頁應用程式網址。這就是可供學生填寫的正式網頁；請把網址貼回本聊天，讓我檢查正式資料讀寫。
6. 在正式網頁按「老師管理」，輸入密碼，選擇開放的班級、設定截止時間，儲存。機械班4人組全班限1組，學生直接登記、先搶先贏，取消後釋出名額。

不需要把這份試算表公開，也不需要讓學生取得試算表編輯權限。

請使用 `Code.gs` 與 `Index.html` 兩份檔案。網頁由 `HtmlService.createHtmlOutputFromFile('Index')` 載入，不依賴 `INDEX_HTML_` 變數。舊的單檔版請整份替換，不要與新 `Code.gs` 同時保留。`appsscript.json` 供需要管理專案資訊的使用者參考。

## 修改與維護

網站規則設定請在「老師管理」操作；「期末分組」P:R欄的設定是摘要，修改摘要不會改變正式規則。

新增或恢復學生前須重新核對班級人數與總報告容量。原始班級工作表最上方連續的學號、姓名為名單來源，下方統計或未繳名單不會重複匯入；轉學生依私密系統資料中的停用學號排除。

「期末分組」A:G欄放分組紀錄、J:M欄放待分組、P:R欄放設定、U:X欄放異動紀錄；隱藏Z欄保存正式狀態，請勿手動修改。其餘三個既有工作表只讀不寫。

請勿在正式填寫期間執行 `setup` 重設密碼。重新執行會撤銷現有老師登入；原有分組資料會保留。

Google Apps Script修改程式後，須到「部署 → 管理部署作業 → 編輯 → 新版本」更新既有部署，才能保留原本給學生的網址。

## GitHub

目前連線有讀寫既有儲存庫的能力，但GitHub拒絕此整合建立新的儲存庫。可先在GitHub建立一個空白儲存庫，再將網址貼回聊天；程式碼已準備好，能接續推送。程式碼不包含管理密碼、學生姓名名單或Google授權憑證。

## 瀏覽器登入相容修正

Google Apps Script內嵌頁面可能無法存取sessionStorage。新版Index.html將老師登入憑證保存在目前頁面的記憶體，避免儲存權限錯誤；重新整理後需重新登入老師管理。

已透過實際Google Apps Script後端驗證新增3人組、另一瀏覽器讀取、老師刪除、日期名額與組員釋出，並回讀原試算表確認測試小組已清除、原設定保留。這次瀏覽器實測先暫時套用新版api函式；正式頁面仍須更新Index.html並部署新版本才能套用修正。

## 表單字體

新版Index.html將輸入欄與主要按鈕設為16px，姓名、組長與說明14px，報告日期23至24px。已在320、390及1280像素寬度確認無橫向溢出。更新只需替換Index.html，或將public/style.css末尾 Larger form text 區塊貼入既有style結尾；儲存後更新既有部署的新版本。

## 機械班4人組規則

4人組由學生直接登記，以第一筆成功送出為準，全班限1組；後端在同一個ScriptLock內重新確認額度。額滿後學生端停用4人選項；老師取消該組後，額度自動釋出。不再使用fourIds指定成員；新版老師設定不會因已有4人組而受舊指定成員欄位影響。規則變更需同時更新Code.gs與Index.html，並更新既有部署的新版本；不需重跑setup，不會清除現有分組。
